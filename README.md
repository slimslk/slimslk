### 🌑 Featured Project: DoEH (Domains of Endless Hunger)
**A Dark Fantasy Distributed Online Survival RPG** set across a fractured multiversal structure of interconnected pocket worlds called Domains.

> *"The greatest enemy is not a creature — but the absence of sustenance itself."*

*   **Core Concept**: In a world plagued by the "Endless Hunger," everything that lives must consume to survive. Food is finite, and survival is the ultimate challenge.
*   **Technical Implementation**: 
    *   **WebSocket Gateway**: High-concurrency **Java/Netty** server for real-time bidirectional traffic.
    *   **Logic Engine**: Asynchronous **Python 3.12** engine managing real-time survival mechanics (Hunger/Energy/Combat).
    *   **IAM Service**: Reactive **Spring WebFlux / R2DBC** authentication service (Java 21).
    *   **Event-Driven**: Full service synchronization via **Apache Kafka**.
